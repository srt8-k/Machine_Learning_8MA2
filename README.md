# 🏎️ Sports Car Price Analysis & Prediction
### Machine Learning Course Repository

Welcome to my Machine Learning repository! This project focuses on analyzing sports car data and understanding the technical factors that drive market prices.

---

## 📖 Overview
This dataset contains information about various sports cars from different manufacturers. It includes technical specifications and performance metrics along with the car price in USD.

> **Note:** This dataset is intended for educational purposes only and was generated using large language models. It is not based on real-world collected data and must not be used for commercial purposes.

---

## 🎯 Objectives
In this repository, I will be uploading all my **Labs** and **Assignments**, focusing on:
* Exploring relationships between performance features and price.
* Identifying trends in sports car pricing.
* Understanding which factors most influence price.
* **Building predictive models** in future assignments to estimate car values.

---

## 📊 Dataset Columns Description

| Column | Description |
| :--- | :--- |
| **Car Make** | Brand of the car (e.g., Porsche, Ferrari, Lamborghini) |
| **Car Model** | Specific model name (e.g., 911, Huracan, 720S) |
| **Year** | Production year of the vehicle |
| **Engine Size (L)** | Engine displacement in liters |
| **Horsepower** | Power output of the engine |
| **Torque (lb-ft)** | Engine torque in pound-feet |
| **0-60 MPH Time** | Acceleration time from 0 to 60 mph (seconds) |
| **Price (USD)** | Car price in US dollars |

---

## 📈 Potential Analysis Areas
Throughout the course, I will work on:
1. **Price Distribution:** Analyzing the spread of sports car prices.
2. **Feature Correlation:** How Horsepower and Torque impact the final cost.
3. **Performance Impact:** The relationship between 0-60 MPH acceleration and price.
4. **Engine Metrics:** How engine size influences overall vehicle performance.
5. **Correlation Matrix:** Visualizing relationships between all numerical features.
